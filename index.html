With an ever-growing number of AI models, choosing the right one for a specific engineering problem is a challenge. This benchmark answers that question through objective, data-driven evaluation
— so teams can make informed decisions, not assumptions.
Benchmark Pipeline
STEP A
Train & Infer
Model + Dataset → Train → Infer → Results
STEP B
Calc Metrics
Inference → Metrics → Summary Report
STEP C
Rank Models
Debiased Weights → Dominance → PageRank
Why — Fair comparison requires identical conditions. Every model must be trained on the same dataset, same scale, same pipeline — no exceptions.

How — Each model goes through the same standardized training and inference process:
1. Select a model, dataset (DeepJEB / DrivAerNet), and data scale (S / M / L / XL)
2. Train on N samples — 2D images at 128×128, or 3D point clouds with 8192 points
3. Generate exactly 500 test samples for standardized evaluation

What — 500 generated samples + training time + inference time
Covers GAN · VAE · Diffusion · Flow · Implicit · Transformer · GNN families
Why — A single metric can be misleading. We measure quality, diversity, and efficiency simultaneously to capture the full picture of model performance.

How — Each model's 500 samples are compared against 500 real samples across three dimensions:
1. Quality — How realistic? (FID, IS, PSNR for 2D · CD, EMD, FPD for 3D · MAE, RMSE, R² for eval)
2. Diversity — How varied? (Precision, Recall, Density, Coverage)
3. Efficiency — How fast and lightweight? (Parameters, Training time, Inference time)

What — A metric report per model with ↑ higher-is-better and ↓ lower-is-better indicators
Covers 2D image · 3D point cloud · 3D field evaluation domains
Why — Simply averaging metrics is unfair — correlated metrics inflate certain aspects, and different scales make direct comparison meaningless. BenchRank solves this.

How — All metric reports are fed into a four-stage ranking pipeline:
1. Debias — Correlated metrics (e.g. MAE & RMSE) are automatically down-weighted so no single aspect dominates
2. Dominance — Every model is compared head-to-head across all metrics, building a "who-beats-whom" network
3. PageRank — The network is scored to produce one global Total Score per model
4. Dual Branch — Two views: Quality-only and Quality + Efficiency (switchable on the leaderboard)
